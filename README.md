# 生日粒子网页使用说明书

[打开生日粒子网页](https://snazzy-sherbet-5a69f1.netlify.app/)

这是一个通过摄像头手势和麦克风声音互动的生日网页。你可以召唤粒子蛋糕、点亮蜡烛、播放生日歌、吹蜡烛许愿，再进入粉色爱心和照片爱心，浏览 34 张回忆照片。

网页入口为 [index.html](./index.html)。本说明对应仓库中的当前版本。

## 使用范围与网站有效期

**本网页仅用于私人生日当天的互动与庆祝，部署网站可能会过期、停用或停止维护。若在线网站已无法使用，可以下载本仓库中的 [index.html](./index.html)，在本地浏览器中继续交互使用。**

## 下载到本地使用

1. 打开仓库中的 `index.html`，下载原始文件并保存为 `index.html`；也可以通过仓库的 `Code → Download ZIP` 下载全部文件后解压。
2. 用电脑浏览器打开本地 `index.html`，点击 `ENTER UNIVERSE`，允许摄像头和麦克风访问，再按下方说明操作。
3. 本地使用时仍需保持联网，以加载程序库、手势识别模型、照片和默认音乐。

如果直接打开文件时遇到浏览器对摄像头或模块加载的限制，可通过本地静态服务访问。若电脑已安装 Python 3，在保存 `index.html` 的文件夹中打开终端，运行：

```bash
python -m http.server 8000
```

然后在浏览器中打开 [本地网页](http://localhost:8000/)，并允许摄像头和麦克风访问。使用结束后，在终端按 `Ctrl+C` 停止本地服务。

## 开始前的准备

- 使用带摄像头和麦克风的电脑，在支持现代网页功能的浏览器中打开网站。
- 保持联网。程序库、手势识别模型、照片和默认音乐都需要从网络加载。
- 允许网站使用摄像头和麦克风。摄像头用于识别手势，麦克风用于吹蜡烛互动。
- 保持正面光线充足，让需要参与操作的手完整出现在左上角预览中。双手动作时，两只手都要进入画面，尽量避免互相遮挡。
- 先调低设备音量，再按需要调整。戴耳机可减少外放声音误触发吹蜡烛的情况。

部署网站使用 HTTPS，方便浏览器提供摄像头和麦克风访问权限。手机与内置浏览器的体验可能因权限、性能和操作方式而不同，完整流程建议在电脑上体验。

## 快速体验完整流程

1. 打开网站，允许摄像头访问。等到出现 `ENTER UNIVERSE` 按钮后，点击进入，再允许麦克风访问。
2. 向摄像头做单手 OK 手势：拇指与食指指尖相接，其他三指伸直。网页开始播放背景音乐。如果播放失败，使用左上角的播放按钮启动音乐。
3. 双手握拳，召唤生日蛋糕。蛋糕出现后等待约 **3 秒**，看到点蜡烛提示再继续。
4. 两只手分别只伸出食指，其他手指收拢。蜡烛点亮后等待约 **1 秒**。
5. 让双手同时左右摇动，开始播放生日歌，蛋糕随之旋转。
6. 生日歌开始约 **9 秒**后，等左上角出现 `BLOW NOW TO WISH!`，朝麦克风吹气。蜡烛熄灭，出现生日祝福、合照粒子和庆祝效果。
7. 祝福出现后等待约 **3 秒**，用双手比出大爱心，进入粉色粒子爱心。
8. 在粉色爱心阶段，先握拳让粒子聚拢，再张开手让粒子散开；完整重复 **2 次**。松开比心姿势后，再用双手比一次大爱心，进入照片爱心。
9. 张开手让照片散开；拇指和食指捏合可随机放大一张照片。张开手返回散开的照片，再次捏合查看下一张。握拳可把散开的照片聚回爱心。

操作过程中，以左上角状态提示和摄像头预览为准。需要等待的阶段不必反复做手势。

## 手势与操作阶段

同一个手势在不同阶段有不同用途。完成生日流程时，请按上述顺序操作。

| 当前阶段 | 手势或动作 | 操作要点 | 网页效果 |
| --- | --- | --- | --- |
| 音乐尚未启动 | 单手 OK | 拇指与食指相接，中指、无名指和小指伸直 | 启动背景音乐，开放后续互动 |
| 初始粒子场景 | 双手握拳 | 双手进入预览并握紧；当前版本也支持只检测到一只手时单手握拳 | 召唤粒子蛋糕 |
| 蛋糕已出现且等待结束 | 双手各伸一根食指 | 食指朝上，其他手指收拢，保持两只手可见 | 点亮蜡烛 |
| 蜡烛已点亮且等待结束 | 双手左右摇动 | 两只手都要有明显的横向移动 | 播放生日歌，蛋糕开始旋转 |
| 出现吹气提示 | 向麦克风吹气 | 等到 `BLOW NOW TO WISH!` 再吹气 | 熄灭蜡烛，显示祝福与庆祝效果 |
| 祝福已展示且等待结束 | 双手大爱心 | 两手食指指尖在上方靠近，两手拇指指尖在下方靠近 | 进入粉色粒子爱心 |
| 粉色粒子爱心 | 握拳后张开 | 先聚拢、再散开，完成两次完整循环 | 解锁照片爱心入口 |
| 已完成两次循环 | 解除比心后再次比心 | 先松开双手，再重新做出大爱心 | 切换为 34 张照片组成的爱心 |
| 照片爱心 | 张开手 | 手掌朝向摄像头，手指充分展开 | 照片向四周散开 |
| 照片散开 | 握拳 | 建议只让一只手参与操作 | 照片聚回爱心 |
| 照片散开 | 拇指与食指捏合 | 其他手指保持展开 | 随机放大一张照片 |
| 单张照片放大 | 张开手 | 拇指与食指也要分开，解除捏合 | 返回照片散开状态 |

双手大爱心是两只手共同围成一个心形。让手指轮廓清楚、食指在拇指上方，通常更容易被识别。

## 照片爱心的浏览方法

进入照片爱心后，建议用一只手操作，另一只手移出摄像头画面，减少不同手势同时出现造成的切换。

**散开与聚拢**：张开手使照片散开，握拳使照片重新组成爱心。照片散开时，移动手掌可以改变三维观察视角，手掌靠近或远离摄像头也会影响画面距离。

**放大查看**：在照片散开后，将拇指和食指指尖捏合，其他手指展开。网页会随机选择一张照片放到中央，同时出现装饰粒子和快门音效。放大期间，手掌移动对三维视角的控制暂停。

**继续浏览**：充分张开手，解除捏合，返回散开状态，再重新捏合。直接保持捏合不会连续切换照片。放大状态下如需重新聚成爱心，应先张开手退出放大，再握拳。

网页优先从本轮尚未查看的照片中随机选择；34 张都看完后，开始下一轮。`PHOTO n/34` 表示本轮已查看的数量，照片按随机顺序出现。

## 按钮和滑块

| 页面控件 | 使用方法与作用 |
| --- | --- |
| `ENTER UNIVERSE` | 进入主画面并初始化音频与摄像头手势识别。 |
| `▶ / ⏸` | 播放或暂停背景音乐。完整手势流程需要保持背景音乐的播放状态。 |
| `LOAD MP3` | 选择电脑中的音频文件，替换本次页面播放的背景音乐。建议使用浏览器可播放的 MP3。 |
| 音量滑块 | 调整背景音乐音量。生日歌和部分音效另行播放；如需控制整体音量，请调整设备音量。 |
| `SPREAD` | 调整粒子形状的展开范围；在 `NEBULA` 场景中拖动会立即重新分布粒子。 |
| `DENSITY` | 调整粒子向目标形状变化的快慢。当前版本中它不改变粒子数量。 |
| `PARTICLE COLOR` | 选择绘图粒子的颜色；星云、生日蛋糕及爱心等场景使用各自的配色。 |
| `NEBULA` | 切换到初始星云场景。 |
| `HEART` | 显示普通粒子爱心。粉色互动爱心和照片爱心需通过生日流程进入。 |
| `DRAW` | 开启或关闭鼠标绘图画布。 |
| `REBOOT` | 重置部分互动状态、暂停背景音乐并回到初始场景。 |
| `↻ RETURN` | 祝福阶段出现的返回按钮，执行与 `REBOOT` 相同的重置操作。 |

首次体验完整流程时，先按手势顺序完成；需要自由探索时，再使用模式按钮。

### 更换背景音乐

1. 先暂停当前背景音乐。
2. 点击 `LOAD MP3`，选择音频文件。
3. 点击播放按钮，或在音乐尚未启动时做 OK 手势。

所选文件只用于当前页面播放，刷新后需要重新选择。切换音乐后，状态栏的歌曲名称可能仍显示预设文字，应以实际播放内容为准。

如果出现 `PLAY FAILED - TRY CLICK ▶`，点击播放暂停按钮；若第一次点击只是切回播放图标，再点击一次启动播放。

### 用鼠标绘制粒子图案

1. 点击 `DRAW`。如果第一次点击没有出现绘图效果，再点击一次。
2. 在主画面中按住鼠标左键拖动，画出文字、爱心或简单线条。
3. 在画布内松开鼠标，粒子会向刚画出的轨迹聚集。
4. 再次点击 `DRAW`，关闭绘图画布。

当前绘图使用鼠标操作。每次按下鼠标会开始一条新轨迹，并清除上一条画布线条，适合一笔画。为完整重放生日互动，刷新网页重新进入更可靠。

## 常见问题

| 遇到的情况 | 处理方法 |
| --- | --- |
| 一直停在 `SYSTEM INITIALIZING` 或画面空白 | 检查网络，刷新重试。网页需要加载网络程序库和识别模型；也请确认浏览器支持三维网页渲染。 |
| 摄像头预览没有画面或没有手部连线 | 检查网站与系统的摄像头权限，关闭其他占用摄像头的程序，调整光线和手的位置。 |
| 音乐没有声音 | 检查设备与网页音量，点击播放按钮；默认音频链接无法加载时，可用 `LOAD MP3` 选择本地音乐。 |
| 蛋糕或蜡烛无法触发 | 保持音乐处于播放状态，等待当前阶段提示结束，并让需要的手势完整出现在预览中。点蜡烛需要两只手。 |
| 双手摇动后没有生日歌 | 确认处于蜡烛点亮后的等待结束阶段，再让双手明显左右移动，避免移出画面。 |
| 吹气没有反应 | 先等生日歌开始约 9 秒、出现吹气提示，再检查麦克风权限和输入设备，靠近麦克风轻吹。 |
| 还没吹气就出现祝福 | 吹气通过声音强度触发，讲话、噪声或外放音乐也可能达到条件。降低外放音量或使用耳机后重新体验。 |
| 粉色爱心无法进入照片爱心 | 完成两次“握拳聚拢后张开散开”，查看状态栏的剩余次数，再解除比心并重新比心。 |
| 放大照片无法退出 | 完全张开手，并把拇指与食指分开。握拳不会直接退出放大状态。 |
| 照片暂时显示 `PHOTO` 占位文字 | 等待照片加载，检查网络和外部图片链接是否可用。 |
| 祝福旁边显示笑脸而非合照 | 当前版本在合照尚未加载成功时使用笑脸替代。 |
| 点击返回后画面仍不正常 | 照片阶段的重置可能不完整，刷新网页可重新开始完整流程。 |
| 页面卡顿 | 关闭其他占用较多资源的程序，缩小浏览器窗口，换用性能更好的电脑。`DENSITY` 不会减少粒子数量。 |

## 当前版本的提示差异

- 如看到 `SHOW 1-4 FINGERS FOR PHOTOS`，当前版本未接入数字手势切换四张图库照片的操作。祝福阶段请用双手比心继续。
- 滑块旁的数值文字没有随拖动更新，参数变化请以实际画面为准。
- `SYSTEM READY` 和 `Camera & Audio Access Granted` 是界面提示；实际权限状态请以浏览器授权结果、摄像头预览和声音输入为准。
- `REBOOT` 与 `RETURN` 不能保证恢复照片阶段的全部显示状态；希望从头体验时，请刷新网页。

## 结束体验与保存

当前网页在浏览器内识别手势和声音强度，未提供录音录像的保存或上传操作。背景音乐文件通过本地选择读取。点击返回或重启按钮后，摄像头和麦克风仍可能保持运行；结束体验时关闭网页。

仓库保存网页源码和说明书，照片、默认音乐、程序库与识别模型仍由外部网址提供。长期保存时，请另外保留完整资源备份，并维护这些链接。后续修改网页，可以更新 `index.html` 后重新部署到现有 Netlify 项目。
